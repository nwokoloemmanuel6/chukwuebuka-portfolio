# Student Portfolio and Academic Planner

COS 106 (Introduction to Web Technologies) term project by Chukwuebuka Nwokolo, Miva Open University.

A multi-page website built with plain HTML, CSS and JavaScript:

- **Home**: photo, welcome message and short bio
- **About Me**: education, career aspirations, skills table, hobbies and a video
- **Projects**: three projects with screenshots
- **Academic Planner**: add, complete and delete study tasks (JavaScript, saved in the browser)
- **Contact**: form with JavaScript checks (no empty fields, valid email, digits-only phone)

Open `index.html` in a browser to view the site.
